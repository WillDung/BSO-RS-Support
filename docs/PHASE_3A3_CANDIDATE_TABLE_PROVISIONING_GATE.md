## 9. AutoNumber Capability Assessment

Microsoft documents creating AutoNumber as `StringAttributeMetadata` with `AutoNumberFormat`, `FormatName` set to `Text`, and a `MaxLength` sufficient for generated values. `{SEQNUM:8}` is a valid sequence-placeholder shape; the sequence length is a minimum and can grow beyond eight digits. See [Microsoft’s AutoNumber column metadata guidance](https://learn.microsoft.com/en-us/power-apps/developer/data-platform/create-auto-number-attributes).

**`AUTONUMBER_CAPABILITY_BLOCKED`** for this proposal: the platform capability and placeholder syntax are documented, but the manifest omits `MaxLength` and does not contain a complete deployable metadata definition. This is a proposal completeness gap, not evidence that Dataverse lacks AutoNumber support. The live environment path and actual metadata acceptance were not verified. Runtime generation cannot be proven before a later separately authorized synthetic-row test.
